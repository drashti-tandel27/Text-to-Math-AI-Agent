\# Text-to-Math AI Agent



\## Overview

A Generative AI-powered Text-to-Math Agent that understands natural language mathematical questions and performs calculations using an AI agent.



\## Technologies Used

\- Python

\- LangChain

\- Groq LLM

\- Calculator Tool

\- Jupyter Notebook



\## Project Structure

\- `app.py` – Main Python application.

\- `Task1\_Text\_to\_Math\_Agent.ipynb` – Assignment 1.

\- `Task2\_Text\_to\_Math\_Agent.ipynb` – Assignment 2.



\## Key Concepts

\- Generative AI

\- Large Language Models (LLMs)

\- AI Agents

\- Tool Calling

\- Natural Language Processing



\## How to Run

1\. Clone the repository.

2\. Create a Python virtual environment.

3\. Install the required dependencies.

4\. Configure your Groq API key securely.

5\. Run:



```bash

python app.py

```
